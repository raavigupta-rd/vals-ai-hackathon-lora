TWIN INSCRIPTIONS

Two stone tablets bear lowercase inscriptions S and T. Count the number of quadruples of 1-based indices (l_1, r_1, l_2, r_2) with 1 <= l_1 <= r_1 <= |S| and 1 <= l_2 <= r_2 <= |T| such that the substring S[l_1 .. r_1] is identical to the substring T[l_2 .. r_2].

Input
The first line contains the non-empty string S.
The second line contains the non-empty string T.

Output
Print a single integer: the total number of matching substring pairs.

Constraints
1 <= |S|, |T| <= 150000
S and T consist of lowercase English letters ('a'-'z').

Sample input 1 (file sample_1.in)
aba
ab

Sample output 1 (file sample_1.out)
4

Limits: 2 seconds and 1024 MiB of memory per test.
