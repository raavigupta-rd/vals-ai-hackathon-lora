FORMATION RANKS

N soldiers stand in a line with skill ratings A_1, A_2, ..., A_N. You want to select a subsequence of indices 1 <= i_1 < i_2 < ... < i_L <= N such that their ratings are strictly increasing:
A_{i_1} < A_{i_2} < ... < A_{i_L}.

Find BOTH:
1. L_max, the maximum possible length of such a strictly increasing subsequence.
2. C, the number of distinct index subsequences (i_1, ..., i_{L_max}) that achieve length L_max, modulo 10^9 + 7.

Input
The first line contains N.
The second line contains A_1 ... A_N.

Output
Print two space-separated integers: L_max and C (modulo 10^9 + 7).

Constraints
1 <= N <= 200000
1 <= A_i <= 10^9

Sample input 1 (file sample_1.in)
6
1 3 2 4 3 5

Sample output 1 (file sample_1.out)
4 3

Sample input 2 (file sample_2.in)
4
7 7 7 7

Sample output 2 (file sample_2.out)
1 4

Limits: 2 seconds and 1024 MiB of memory per test.
