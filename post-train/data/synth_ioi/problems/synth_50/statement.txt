EXACT-LENGTH TRAILS

A national forest has N clearings numbered 1 to N connected by N - 1 bidirectional trails forming a tree. Count how many unordered pairs of distinct clearings {u, v} have a unique simple path between them consisting of EXACTLY K trails.

Input
The first line contains N and K.
Each of the next N - 1 lines contains two clearings connected by a trail.

Output
Print a single integer: the number of unordered pairs at distance K.

Constraints
2 <= N <= 180000
1 <= K < N

Sample input 1 (file sample_1.in)
5 2
1 2
2 3
2 4
4 5

Sample output 1 (file sample_1.out)
4

Limits: 2 seconds and 1024 MiB of memory per test.
