CANAL LOCKS

N freight barges arrive in a single file numbered 1 to N, where barge i has displacement W_i. You must divide the line of barges into exactly K non-empty contiguous batches to pass through a canal lock one batch at a time.

If a batch consists of barges L, L+1, ..., R, the water turbulence cost of locking that batch is (W_L + W_{L+1} + ... + W_R)^2. Find the minimum total turbulence cost summed across all K batches.

Input
The first line contains N and K.
The second line contains W_1 ... W_N.

Output
Print a single integer: the minimum possible total turbulence cost.

Constraints
1 <= K <= 20
K <= N <= 100000
1 <= W_i <= 10000

Sample input 1 (file sample_1.in)
5 2
3 1 4 1 5

Sample output 1 (file sample_1.out)
100

Limits: 2 seconds and 1024 MiB of memory per test.
