SIGNAL INTERFERENCE

N radio beacons stand in a line numbered 1 to N. Beacon i broadcasts on frequency code A_i. You are given Q probe queries: each query specifies L, R, and X, and asks for the maximum bitwise XOR value (A_i XOR X) over all beacons i with L <= i <= R.

Input
The first line contains N and Q.
The second line contains A_1 ... A_N.
Each of the next Q lines contains L, R, and X.

Output
For each query print the maximum value of (A_i XOR X) on its own line.

Constraints
1 <= N, Q <= 180000
0 <= A_i, X < 2^30
1 <= L <= R <= N

Sample input 1 (file sample_1.in)
5 3
3 10 5 25 2
1 5 5
1 3 6
2 4 12

Sample output 1 (file sample_1.out)
28
12
21

Limits: 2 seconds and 1024 MiB of memory per test.
