ORCHARD MEX

An orchard row has N fruit trees numbered 1 to N. Tree i bears fruit of variety A_i (a non-negative integer). You are asked Q questions. Each question gives two integers L and R, and asks for the smallest non-negative integer variety (0, 1, 2, ...) that does NOT appear anywhere among trees L, L+1, ..., R.

Input
The first line contains N and Q.
The second line contains A_1 ... A_N.
Each of the next Q lines contains L and R.

Output
For each question print the smallest missing non-negative integer on its own line.

Constraints
1 <= N, Q <= 200000
0 <= A_i <= N
1 <= L <= R <= N

Sample input 1 (file sample_1.in)
6 4
0 2 1 0 3 1
1 3
2 5
1 6
5 6

Sample output 1 (file sample_1.out)
3
4
4
0

Limits: 2 seconds and 1024 MiB of memory per test.
