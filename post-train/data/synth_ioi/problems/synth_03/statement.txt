FLOODED TERRACES

Along a hillside stand N stone walls numbered 1 to N, where wall i has height H_i. You are asked Q independent questions. Each question specifies L and R: imagine that only walls L, L+1, ..., R exist (water spills freely off to the left of L and to the right of R). After heavy rain, water settles above each wall i (L <= i <= R) up to the height min(max_{L <= j <= i} H_j, max_{i <= j <= R} H_j). Find the total volume of trapped water summed over all i from L to R.

Input
The first line contains N and Q.
The second line contains H_1 ... H_N.
Each of the next Q lines contains L and R.

Output
For each question print the total trapped water volume on its own line.

Constraints
1 <= N, Q <= 200000
1 <= H_i <= 10^9
1 <= L <= R <= N

Sample input 1 (file sample_1.in)
7 4
4 1 3 2 5 1 3
1 5
2 7
3 6
4 4

Sample output 1 (file sample_1.out)
6
3
1
0

Limits: 2 seconds and 1024 MiB of memory per test.
