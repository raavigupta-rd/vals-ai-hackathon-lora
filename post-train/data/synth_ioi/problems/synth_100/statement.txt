HISTORIC PEAK LEDGER

A reservoir control system monitors N gauges A_1, ..., A_N and also maintains for each gauge i its historic peak B_i, initialized to B_i = A_i.

Process Q operations of four types:
- 1 L R X : for each i in [L, R], set A_i <- A_i + X, then B_i <- max(B_i, A_i).
- 2 L R V : for each i in [L, R], set A_i <- max(A_i, V), then B_i <- max(B_i, A_i).
- 3 L R V : for each i in [L, R], set A_i <- V, then B_i <- max(B_i, A_i).
- 4 L R   : print max_{L <= i <= R} A_i and max_{L <= i <= R} B_i.

Input
The first line contains N and Q.
The second line contains initial values A_1 ... A_N.
Each of the next Q lines describes an operation.

Output
For each type-4 operation print two space-separated integers: the current range maximum and the historic peak range maximum.

Constraints
1 <= N, Q <= 150000
-10^8 <= A_i, X, V <= 10^8
1 <= L <= R <= N

Sample input 1 (file sample_1.in)
5 7
1 4 2 -3 5
1 1 4 3
4 1 5
3 2 5 -10
4 2 5
2 1 5 6
1 3 5 4
4 1 5

Sample output 1 (file sample_1.out)
7 7
-10 7
10 10

Sample input 2 (file sample_2.in)
3 4
-5 -2 -8
1 1 3 -4
4 1 3
2 2 3 0
4 1 3

Sample output 2 (file sample_2.out)
-6 -2
0 0

Limits: 2 seconds and 1024 MiB of memory per test.
