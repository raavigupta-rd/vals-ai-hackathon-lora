SEGMENTED CONVOYS

A logistics fleet must divide a sequence of N crates with positive weights A_1, A_2, ..., A_N (preserving their order) into EXACTLY K non-empty contiguous convoys.

If convoy t carries crates L_t, L_t + 1, ..., R_t with total weight S_t = A_{L_t} + ... + A_{R_t}, road wear imposes a quadratic surcharge of (S_t)^2.

Find the minimum possible total surcharge sum_{t=1..K} (S_t)^2 across all valid partitions into K non-empty contiguous convoys.

Input
The first line contains N and K.
The second line contains A_1 ... A_N.

Output
Print a single integer: the minimum possible sum of squared convoy weights.

Constraints
1 <= K <= N <= 150000
1 <= A_i <= 2000

Sample input 1 (file sample_1.in)
6 3
3 1 4 1 5 2

Sample output 1 (file sample_1.out)
90

Sample input 2 (file sample_2.in)
4 4
7 2 5 3

Sample output 2 (file sample_2.out)
87

Limits: 2 seconds and 1024 MiB of memory per test.
