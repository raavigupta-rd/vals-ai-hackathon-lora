MOUNTAIN COURIERS

A mountain province has N villages numbered 1 to N connected by M bidirectional roads. Road i connects villages U_i and V_i and crosses a pass of altitude W_i. The road network is connected (multiple roads may connect the same pair of villages).

You are asked Q courier queries. Each query specifies a start village A and a destination village B: find the minimum oxygen rating R such that a courier can travel from A to B using only roads with altitude at most R (if A = B, the answer is 0).

Input
The first line contains N, M, and Q.
Each of the next M lines contains U_i, V_i, and W_i.
Each of the next Q lines contains A and B.

Output
For each query print the minimum required altitude rating on its own line.

Constraints
2 <= N <= 200000
N - 1 <= M <= 200000
1 <= Q <= 200000
1 <= U_i, V_i <= N, U_i != V_i
1 <= W_i <= 10^9

Sample input 1 (file sample_1.in)
4 5 3
1 2 5
2 3 8
1 3 6
3 4 4
2 4 9
1 4
2 4
3 3

Sample output 1 (file sample_1.out)
6
6
0

Limits: 2 seconds and 1024 MiB of memory per test.
