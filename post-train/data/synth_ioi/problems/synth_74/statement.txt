PAIRWISE DISTANCES

Given N integers A_1, A_2, ..., A_N, consider the multiset of all N * (N - 1) / 2 pairwise absolute differences |A_i - A_j| for 1 <= i < j <= N, sorted in non-decreasing order:
d_1 <= d_2 <= ... <= d_{N*(N-1)/2}.

Given K, find BOTH:
1. d_K, the K-th smallest pairwise absolute difference.
2. S_K = d_1 + d_2 + ... + d_K, the sum of the K smallest pairwise absolute differences.

Input
The first line contains N and K.
The second line contains A_1 ... A_N.

Output
Print two space-separated integers: d_K and S_K.

Constraints
2 <= N <= 200000
1 <= K <= N * (N - 1) / 2
0 <= A_i <= 10^8

Sample input 1 (file sample_1.in)
4 4
1 5 2 9

Sample output 1 (file sample_1.out)
4 12

Sample input 2 (file sample_2.in)
4 3
5 5 5 8

Sample output 2 (file sample_2.out)
0 0

Limits: 2 seconds and 1024 MiB of memory per test.
