RANKED GRANARIES

A valley has N granaries in a row numbered 1 to N, where granary i stores A_i sacks of grain. You are asked Q audit queries. Each query specifies L, R, and K (1 <= K <= R - L + 1): if the values A_L, A_{L+1}, ..., A_R are sorted in non-decreasing order as B_1 <= B_2 <= ... <= B_{R-L+1}, report BOTH B_K (the K-th smallest value) AND the sum B_1 + B_2 + ... + B_K.

Input
The first line contains N and Q.
The second line contains A_1 ... A_N.
Each of the next Q lines contains L, R, and K.

Output
For each query print two space-separated integers on its own line: B_K and the sum of the K smallest values.

Constraints
1 <= N, Q <= 180000
1 <= A_i <= 10^9
1 <= L <= R <= N
1 <= K <= R - L + 1

Sample input 1 (file sample_1.in)
6 4
5 1 4 1 3 9
1 6 3
2 5 2
1 4 4
6 6 1

Sample output 1 (file sample_1.out)
3 5
1 2
5 11
9 9

Limits: 2 seconds and 1024 MiB of memory per test.
