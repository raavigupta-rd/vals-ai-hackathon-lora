SURVEYOR BEACONS

A mountain range has N survey beacons, where beacon i is located at integer coordinates (X_i, Y_i). You are given Q directional queries: each query gives a non-zero integer vector (A, B) and asks for the maximum value of A * X_i + B * Y_i over all beacons i = 1, 2, ..., N.

Input
The first line contains N and Q.
Each of the next N lines contains X_i and Y_i.
Each of the next Q lines contains A and B (not both zero).

Output
For each query print the maximum dot product on its own line.

Constraints
1 <= N, Q <= 200000
-10^9 <= X_i, Y_i, A, B <= 10^9
(A, B) != (0, 0)

Sample input 1 (file sample_1.in)
4 4
1 2
4 1
-3 5
0 -4
2 3
1 -1
-1 0
0 -2

Sample output 1 (file sample_1.out)
11
4
3
8

Limits: 2 seconds and 1024 MiB of memory per test.
