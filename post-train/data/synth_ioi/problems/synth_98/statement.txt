HARMONIC BEACON RECURRENCE

A deep-space harmonic beacon emits pulses governed by a linear recurrence of order D. You are given the initial pulse amplitudes A_0, A_1, ..., A_{D-1} and recurrence coefficients C_1, C_2, ..., C_D. For every integer n >= D,
A_n = (C_1 * A_{n-1} + C_2 * A_{n-2} + ... + C_D * A_{n-D}) mod 998244353.

Compute A_K mod 998244353.

Input
The first line contains D and K.
The second line contains A_0 ... A_{D-1}.
The third line contains C_1 ... C_D.

Output
Print A_K modulo 998244353.

Constraints
1 <= D <= 8000
0 <= K <= 10^18
0 <= A_i, C_j < 998244353

Sample input 1 (file sample_1.in)
2 10
0 1
1 1

Sample output 1 (file sample_1.out)
55

Sample input 2 (file sample_2.in)
3 7
1 2 4
2 3 5

Sample output 2 (file sample_2.out)
2229

Limits: 2 seconds and 1024 MiB of memory per test.
