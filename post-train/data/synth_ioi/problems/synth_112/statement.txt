BITWISE CONDUIT GATES

An array of N 30-bit registers holds non-negative integers A_1, ..., A_N.

Process Q operations of three types:
- 1 L R X : for each i in [L, R], set A_i <- A_i & X (bitwise AND).
- 2 L R X : for each i in [L, R], set A_i <- A_i | X (bitwise OR).
- 3 L R   : print two space-separated integers: max_{L <= i <= R} A_i and sum_{i=L}^R A_i.

Input
The first line contains N and Q.
The second line contains A_1 ... A_N.
Each of the next Q lines describes an operation in one of the formats above.

Output
For each type-3 operation print the range maximum and range sum separated by a space.

Constraints
1 <= N, Q <= 150000
0 <= A_i, X < 2^30
1 <= L <= R <= N

Sample input 1 (file sample_1.in)
5 6
7 12 5 9 15
1 1 4 13
3 1 5
2 2 5 6
3 2 4
1 1 5 8
3 1 5

Sample output 1 (file sample_1.out)
15 46
15 36
8 24

Sample input 2 (file sample_2.in)
4 4
0 0 0 0
2 1 3 10
2 2 4 5
3 1 4
1 1 4 12

Sample output 2 (file sample_2.out)
15 45

Limits: 2 seconds and 1024 MiB of memory per test.
