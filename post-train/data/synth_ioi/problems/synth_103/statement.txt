ROTATIONAL MOSAIC BRACELETS

A jeweler crafts circular bracelets consisting of N beads arranged in a ring, each chosen from K gem types numbered 1 to K. You are given a K x K compatibility matrix M where M_{u,v} in {0, 1} equals 1 if gem type u may be followed immediately clockwise by gem type v, and 0 otherwise (including bead N followed clockwise by bead 1).

Two valid bracelets are considered identical if one can be obtained from the other by a cyclic rotation (rotations by 0, 1, ..., N - 1 positions; reflections are NOT allowed).

Count the number of distinct valid bracelets modulo 998244353.

Input
The first line contains N and K.
Each of the next K lines contains K integers M_{u,1} ... M_{u,K} (each 0 or 1).

Output
Print the number of distinct bracelets modulo 998244353.

Constraints
1 <= N <= 900000000
1 <= K <= 20
M_{u,v} in {0, 1}

Sample input 1 (file sample_1.in)
4 2
1 1
1 0

Sample output 1 (file sample_1.out)
3

Sample input 2 (file sample_2.in)
6 3
0 1 1
1 0 1
1 1 1

Sample output 2 (file sample_2.out)
38

Limits: 2 seconds and 1024 MiB of memory per test.
