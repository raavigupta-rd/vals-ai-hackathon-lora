TERRACED AQUEDUCTS

An imperial engineer is grading N aqueduct piers in sequence. Pier i currently sits at integer elevation A_i, and raising or lowering pier i to integer elevation B_i costs W_i * |B_i - A_i| gold per unit of vertical change.

Hydraulic flow requires that for every consecutive pair of piers (i - 1, i) with 2 <= i <= N, the elevation step satisfies:
L_i <= B_i - B_{i-1} <= R_i.

Choose integer elevations B_1, B_2, ..., B_N (which may be negative, zero, or positive) satisfying all N - 1 step bounds to minimize the total earthwork cost sum_{i=1..N} W_i * |B_i - A_i|.

Input
The first line contains N.
The second line contains A_1 ... A_N.
The third line contains W_1 ... W_N.
Each of the next N - 1 lines contains two integers L_i and R_i (for i = 2, ..., N).

Output
Print a single integer: the minimum possible total cost.

Constraints
1 <= N <= 180000
-10^7 <= A_i <= 10^7
1 <= W_i <= 10^4
-10^4 <= L_i <= R_i <= 10^4

Sample input 1 (file sample_1.in)
4
10 2 9 1
3 2 4 5
-2 1
0 3
-4 -1

Sample output 1 (file sample_1.out)
31

Sample input 2 (file sample_2.in)
3
0 100 0
1 10 1
-5 5
-5 5

Sample output 2 (file sample_2.out)
190

Limits: 2 seconds and 1024 MiB of memory per test.
