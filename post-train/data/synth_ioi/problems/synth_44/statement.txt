SIGNAL MODULATORS

An array of N signal amplifiers is numbered 1 to N, where amplifier i initially outputs power A_i. Process Q operations of three types:
- 1 L R M: for every i from L to R, replace A_i with (A_i mod M).
- 2 P X: set A_P to X.
- 3 L R: report the sum A_L + A_{L+1} + ... + A_R.

Input
The first line contains N and Q.
The second line contains A_1 ... A_N.
Each of the next Q lines describes an operation in one of the three formats above. At least one operation is of type 3.

Output
For each operation of type 3, print the range sum on its own line.

Constraints
1 <= N, Q <= 180000
0 <= A_i, X <= 10^9
1 <= M <= 10^9
1 <= P <= N
1 <= L <= R <= N

Sample input 1 (file sample_1.in)
5 5
10 7 15 4 9
3 1 5
1 2 4 6
3 1 5
2 3 20
3 2 5

Sample output 1 (file sample_1.out)
45
27
34

Limits: 2 seconds and 1024 MiB of memory per test.
