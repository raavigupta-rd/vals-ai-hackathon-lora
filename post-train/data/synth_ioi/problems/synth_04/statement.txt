SIGNAL RELAYS

Across a desert plain are N signal relay towers. Tower i stands at integer coordinates (X_i, Y_i) and has transmission capacity W_i (multiple towers may share the same coordinates). You are asked Q sector queries. Each query specifies X_1, Y_1, X_2, Y_2 and asks for the sum of capacities W_i over all towers satisfying X_1 <= X_i <= X_2 and Y_1 <= Y_i <= Y_2.

Input
The first line contains N and Q.
Each of the next N lines contains X_i, Y_i, and W_i.
Each of the next Q lines contains X_1, Y_1, X_2, and Y_2.

Output
For each sector query print the total capacity on its own line.

Constraints
1 <= N, Q <= 200000
1 <= X_i, Y_i, W_i <= 10^9
1 <= X_1 <= X_2 <= 10^9
1 <= Y_1 <= Y_2 <= 10^9

Sample input 1 (file sample_1.in)
5 3
1 2 10
3 4 20
3 2 5
6 5 100
1 2 7
1 1 3 4
2 2 6 4
5 5 5 5

Sample output 1 (file sample_1.out)
42
25
0

Limits: 2 seconds and 1024 MiB of memory per test.
