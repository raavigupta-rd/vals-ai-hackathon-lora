XOR HIGHWAY

There are N data centers numbered 1 to N, where data center i has routing key A_i. You can build a bidirectional fiber link between ANY pair of data centers (i, j) at a cost equal to the bitwise XOR of their keys, A_i XOR A_j.

Find the minimum total cost required to connect all N data centers into a single connected network.

Input
The first line contains N.
The second line contains A_1 ... A_N.

Output
Print a single integer: the minimum spanning tree cost.

Constraints
1 <= N <= 160000
0 <= A_i < 2^30

Sample input 1 (file sample_1.in)
5
1 2 3 4 5

Sample output 1 (file sample_1.out)
8

Sample input 2 (file sample_2.in)
4
7 7 10 10

Sample output 2 (file sample_2.out)
13

Limits: 2 seconds and 1024 MiB of memory per test.
