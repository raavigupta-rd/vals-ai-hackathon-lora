INVERSION SLICES

You are given an integer array A_1, A_2, ..., A_N and an integer K. You must partition the array into AT MOST K non-empty contiguous segments.

Within a single segment [L, R], an inversion is a pair of indices (i, j) with L <= i < j <= R and A_i > A_j.

Find the minimum possible value of M such that the array can be partitioned into at most K contiguous segments where EVERY segment contains at most M internal inversions.

Input
The first line contains N and K.
The second line contains A_1 ... A_N.

Output
Print a single integer: the minimum achievable maximum inversions in any segment.

Constraints
1 <= K <= N <= 100000
1 <= A_i <= 10^9

Sample input 1 (file sample_1.in)
7 2
5 1 4 2 6 3 1

Sample output 1 (file sample_1.out)
4

Sample input 2 (file sample_2.in)
5 5
9 7 5 3 1

Sample output 2 (file sample_2.out)
0

Limits: 2 seconds and 1024 MiB of memory per test.
