FLOOR HARMONICS

You are given N positive integers A_1, A_2, ..., A_N. Compute the sum over ALL ordered pairs (i, j) with 1 <= i <= N and 1 <= j <= N of floor(A_i / A_j).

Input
The first line contains N.
The second line contains A_1 ... A_N.

Output
Print a single integer: the value of sum_{i=1..N} sum_{j=1..N} floor(A_i / A_j).

Constraints
1 <= N <= 200000
1 <= A_i <= 500000

Sample input 1 (file sample_1.in)
4
2 5 7 3

Sample output 1 (file sample_1.out)
14

Limits: 2 seconds and 1024 MiB of memory per test.
