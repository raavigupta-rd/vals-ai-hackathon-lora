RIVAL OUTPOSTS

A frontier region has N outposts numbered 1 to N connected by M bidirectional roads, where road i connects U_i and V_i with length W_i. Outpost u belongs to clan C_u.

For EVERY outpost u = 1, 2, ..., N, find the minimum road distance from u to any outpost v belonging to a DIFFERENT clan (C_v != C_u), or report -1 if no such outpost can be reached from u.

Input
The first line contains N and M.
The second line contains C_1 ... C_N.
Each of the next M lines contains U_i, V_i, and W_i.

Output
Print N space-separated integers on a single line: the answer for outposts 1, 2, ..., N.

Constraints
2 <= N <= 180000
1 <= M <= 200000
1 <= C_u <= N
1 <= U_i, V_i <= N, U_i != V_i
1 <= W_i <= 10^8

Sample input 1 (file sample_1.in)
5 5
1 1 2 2 3
1 2 4
2 3 7
3 4 2
4 5 5
1 4 20

Sample output 1 (file sample_1.out)
11 7 7 5 5

Limits: 2 seconds and 1024 MiB of memory per test.
