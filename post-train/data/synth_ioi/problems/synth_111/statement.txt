DYNAMIC CANYON SPAN

A canyon trail system consists of N camps numbered 1 to N connected by N - 1 bidirectional trails forming a tree. Trail i (1 <= i <= N - 1) connects camps U_i and V_i and initially has length W_i.

Process Q trail updates. Each update gives a trail index eid (1 <= eid <= N - 1) and a new positive length nw, permanently replacing trail eid's length with nw. After each update, print the diameter of the tree — the maximum shortest-path distance between any pair of camps.

Input
The first line contains N and Q.
Each of the next N - 1 lines contains U_i, V_i, and W_i.
Each of the next Q lines contains eid and nw.

Output
After each update print the updated tree diameter on its own line.

Constraints
2 <= N <= 120000
1 <= Q <= 120000
1 <= W_i, nw <= 10^9

Sample input 1 (file sample_1.in)
5 4
1 2 5
2 3 6
2 4 4
4 5 7
1 10
4 1
2 20
3 2

Sample output 1 (file sample_1.out)
21
16
30
30

Sample input 2 (file sample_2.in)
3 3
1 2 8
2 3 9
1 3
2 1
1 15

Sample output 2 (file sample_2.out)
12
4
16

Limits: 2 seconds and 1024 MiB of memory per test.
