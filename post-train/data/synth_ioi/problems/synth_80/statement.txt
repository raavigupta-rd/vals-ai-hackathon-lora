TOWER SPACING

Along a straight highway, a telecom company must erect N relay towers. For each i = 1, 2, ..., N, tower i has two permitted site coordinates, A_i and B_i, and you must build tower i at EITHER X_i = A_i OR X_i = B_i.

To minimize signal interference, you want the minimum distance between any two erected towers,
min_{1 <= i < j <= N} |X_i - X_j|,
to be as LARGE as possible.

Find the maximum achievable value of min_{1 <= i < j <= N} |X_i - X_j|.

Input
The first line contains N.
Each of the next N lines contains two integers A_i and B_i.

Output
Print a single integer: the maximum possible minimum pairwise distance between chosen tower sites.

Constraints
2 <= N <= 20000
0 <= A_i, B_i <= 10^9

Sample input 1 (file sample_1.in)
3
1 9
3 6
2 12

Sample output 1 (file sample_1.out)
5

Sample input 2 (file sample_2.in)
2
5 5
5 5

Sample output 2 (file sample_2.out)
0

Limits: 2 seconds and 1024 MiB of memory per test.
