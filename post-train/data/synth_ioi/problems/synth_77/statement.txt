OASIS PIPELINES

In a desert basin there are N oases at integer coordinates (X_i, Y_i) for i = 1, 2, ..., N. Connecting oasis i and oasis j with an east-west / north-south pipeline costs their rectilinear (Manhattan) distance:
|X_i - X_j| + |Y_i - Y_j|.

Find the minimum total pipeline length required to connect all N oases into one connected network.

Input
The first line contains N.
Each of the next N lines contains X_i and Y_i.

Output
Print a single integer: the minimum total Manhattan spanning tree length.

Constraints
1 <= N <= 100000
0 <= X_i, Y_i <= 10^9

Sample input 1 (file sample_1.in)
4
0 0
3 1
1 4
4 4

Sample output 1 (file sample_1.out)
11

Sample input 2 (file sample_2.in)
3
5 5
5 5
2 9

Sample output 2 (file sample_2.out)
7

Limits: 2 seconds and 1024 MiB of memory per test.
